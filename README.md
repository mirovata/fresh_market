## Краткое описание

__Fresh Basket AI__ — умная универсальная корзина внутри Super App банка: пользователь собирает список продуктов (не выбирая магазин), система автоматически сравнивает все доступные магазины Fresh Market по итоговой цене, наличию, времени доставки и расстоянию.

## Какие проблемы решает

Много времени уходит на ручное сравнение магазинов.  Непрозрачность итоговой выгоды (цена + доставка).  Низкая конверсия из‑за множества шагов. Целевая аудитория Клиенты Super App (занятые люди, семьи, студенты).  Магазины‑партнёры (малые сети получают видимость).  Продуктовые и аналитические команды банка. Ключевые возможности Универсальная корзина без выбора магазина.  Сравнение итоговой стоимости корзины (цена + доставка + бонусы).  Сортировка/фильтрация: цена, ETA, расстояние, цена/скорость, партнёрские предложения. Прозрачное партнёрское продвижение (бейджи, premium‑позиции).  Возможность передачи корзины в сервис выбранного магазина и оформления заказа. Архитектура и компоненты Frontend (Super App): компоненты корзины, экран сравнения, диалог с ИИ.  Backend: Fresh Basket API — агрегатор, калькулятор корзины, ранжировщик.  SKU matching: унификация товаров между магазинами.  Geoservice: расчёт расстояний и зон доставки.  AI Service: генерация рецептов и трансформация в список ингредиентов.

## Как развернуть проект

Требуется: __Docker__ 

Клонировать репозиторий 

~~~
git clone git@repo.example:fresh-basket-ai.git 
cd fresh-basket-ai 
~~~

Настроить .env (пример ниже) и создать секреты (API ключи магазинов, геосервис) 

Запустить инфраструктуру (локально) 

~~~
docker-compose up --build 
~~~

__Backend__ (если запускать отдельно) 

~~~
cd backend 
python -m venv venv 
source venv/bin/activate 
pip install -r requirements.txt 
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000 
~~~

__Frontend__

~~~
cd frontend 
npm install 
npm run dev 
~~~
